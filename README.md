# Wandering Monster Table's 5e Equipment Shop

A local-first web tool for browsing D&D equipment, building an equipment cart, and exporting purchases as Markdown.

## Installation

Requires Python 3.

Clone the repository:

git clone <repository-url>
cd dnd-equipment-shop

Start the local development server:

python server.py

Open http://localhost:8000 in a web browser.

## Development

Developed with HTML, CSS, JavaScript, and Python. AI tools may be used during development for coding assistance, debugging, and documentation.

The application itself does not use LLMs, external APIs, or online queries.
